# SK Sungai Papan — Laman Utama

Homepage rasmi untuk **Sekolah Kebangsaan Sungai Papan (JBA3024), Kota Tinggi, Johor**.

## Struktur
- `index.html` — halaman utama
- `style.css` — reka bentuk responsif
- `script.js` — menu mudah alih dan tahun automatik

## GitHub Pages
Aktifkan **Settings → Pages → Deploy from a branch → main / root** untuk menerbitkan laman ini melalui GitHub Pages.

> Nota: Kandungan seperti alamat penuh, nombor telefon, pautan media sosial, lencana sekolah dan pengumuman sebenar boleh ditambah kemudian.
